## Task 1(i): Explain the prediction output and compare approaches

The prediction table pairs each company identifier with Gemini's predicted stock price. In the results table, `stock_price` is the value supplied in the source CSV, `predicted_stock_price` is Gemini's estimate, and `absolute_error` is the absolute difference between the two. The mean absolute error (MAE) is the average of those row-level differences, measured in the same units as stock price. A lower MAE means smaller errors on these rows; it does not prove the model will predict future prices well. The plot places each company ID on the horizontal axis and shows the source and predicted values as separate series, so overestimates and underestimates are easy to spot.

The supplied finance file has 32 records across eight monthly dates and four company IDs. It contains revenue, earnings, P/E ratio, market capitalization, trading volume, and stock price. The predictions and MAE will be generated only after I run the notebook with my own Gemini API key; I have not filled in made-up output. The file and the car file are labeled synthetic in the starter README, so their patterns are practice examples and should not be described as real market findings.

In Assignments 2 and 3, the earlier workflow involved using AI to help write code for an analysis. Here, I send the dataset itself to a foundation model through a prompt and ask that model to analyze the data and return predictions. Python still handles loading, parsing, matching, measuring errors, and plotting, but Gemini supplies the natural-language analysis and prediction values. The result depends on a prompt and may vary between runs, unlike a deterministic calculation from a fixed algorithm. As in the assignment instructions, this is a demonstration and the evaluation is on the same rows included in the prompt, not on a separate holdout set.

## Task 1(ii): Explain the code, cell by cell

1. **Install.** `!pip -q install google-generativeai pandas matplotlib` installs the Gemini client, pandas, and Matplotlib in Colab. `-q` reduces installation messages.
2. **Imports.** `os` checks for an environment variable, `re` cleans response text, `io` wraps text as an in-memory file, and `getpass` securely prompts for a key. `pandas` manages tabular data, `matplotlib.pyplot` draws the chart, and `google.generativeai` connects to Gemini.
3. **API key setup.** `os.environ.get("GEMINI_API_KEY")` first looks for a key already provided in the session. If it is missing, `getpass.getpass(...)` asks for it without echoing the secret. `genai.configure(...)` authenticates the client, and `GenerativeModel(...)` selects the handout's `gemini-2.0-flash-lite` model. The key should never be typed into a committed notebook.
4. **Upload and load.** `files.upload()` opens Colab's file picker. The code prefers `finance_data.csv`, falling back to the uploaded filename if necessary. `pd.read_csv` reads the file into `df`. `head()` previews the first five rows, `shape` reports row and column counts, and `info()` lists column names, types, and nonmissing counts.
5. **Prepare analysis prompt.** `df.to_csv(index=False)` serializes the table without adding a pandas row-number column. The f-string embeds the entire CSV in `analysis_prompt`. That prompt requests trends, metrics, relationships, and unusual observations, asks for concrete examples, and warns against treating correlation as causation. `generate_content` sends it to Gemini; `analysis_response.text` is the written analysis printed to the notebook.
6. **Prepare prediction prompt.** `prediction_prompt` identifies `stock_price` as the value to predict and `company_id` as the row key. It explicitly says not to use the actual target as an input and requests one row per identifier in a two-column CSV. Gemini's response is stored in `prediction_response`; `.text` extracts the text, which is printed for inspection and retained as `raw_prediction_text`.
7. **Parse and validate output.** `response_to_dataframe` trims whitespace, removes optional triple-backtick fences with regular expressions, locates the expected CSV header even if Gemini adds a leading sentence, joins the remaining lines, and calls `pd.read_csv` on an in-memory text stream. The next lines strip whitespace from column names, locate the identifier and prediction columns without case sensitivity, rename them to standard names, coerce prices to numeric, and discard rows without a numeric prediction. The duplicate, missing, extra, and row-count checks catch incomplete or mismatched output. Finally, a validated one-to-one merge attaches each prediction to the matching original company row; the notebook displays a preview and the matched-row count.
8. **Error calculation.** The subtraction compares actual and predicted stock price; `.abs()` removes the sign so over- and underestimates count as positive error. The printed MAE is the mean absolute error rounded to two decimals. The displayed table shows each identifier, actual value, prediction, and absolute error.
9. **Plot.** `reset_index` makes a clean plotting table. `figure` sets chart size; the two `plot` calls draw actual and predicted series with different markers. The remaining calls rotate crowded labels, add axis labels, title, legend, adjust spacing, and display the chart.
10. **Save output.** `to_csv(..., index=False)` writes the joined source data, predictions, and error column to `ai_prediction_results.csv`. `files.download` downloads it from Colab.
